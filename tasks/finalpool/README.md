# Final Pool

This directory contains all implemented tasks from the BenchTasksCollv3 project.

Tasks are verified against the requirements in `tasks/examples/example-task/`:
- `docs/agent_system_prompt.md` must be non-empty and in English
- `docs/task.md` must be non-empty and in English
- `docs/user_system_prompt.md` (optional) must be in English if non-empty

Each subdirectory represents an implemented task.
